# AttendX-Test-Scripts

## Project Description

This repository contains sample automated test scripts
for a student attendance application.

## Test Scripts

1. login_test.py - Tests valid login, invalid password,
   and empty login fields.
2. attendance_test.py - Tests attendance marking,
   empty student ID, and absent student.

## Technology

- Python
- unittest
- Git
- GitHub

## How to Run

Run the login tests:
python login_test.py

Run the attendance tests:
python attendance_test.py
